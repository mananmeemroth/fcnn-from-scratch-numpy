# Neural Network From Scratch (NumPy)

## Overview
This project implements a 3-layer Fully Connected Neural Network using only NumPy and standard Python libraries — no PyTorch, TensorFlow, or Keras.

The goal was to understand deep learning at the mathematical and implementation level.

---

## Implemented Components

- He weight initialization
- Manual forward propagation (Z = WX + b)
- ReLU activation
- Binary cross-entropy loss
- Backpropagation using chain rule
- Stochastic Gradient Descent (SGD)
- Training loop with loss tracking

---

## Dataset
UCI Adult Census Income Dataset

---

## Results
- Achieved >75% test accuracy
- Verified stable gradient updates
- Observed convergence through loss reduction

---

## Key Learnings

- How gradients are derived and propagated
- Why initialization impacts convergence
- The mechanics behind SGD updates
- What actually happens inside a “black box” model
